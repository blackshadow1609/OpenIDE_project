# Bitumen Parser — сравнение цен на мастику ТехноНИКОЛЬ

Парсер трёх интернет-магазинов, который собирает цены на битумную
мастику ТехноНИКОЛЬ, нормализует названия товаров и строит сводную
таблицу «где выгоднее покупать».

## Задача

Автоматизировать сравнение цен на один и тот же товар у разных
поставщиков, несмотря на:

- разные форматы названий («№31 морозостойкая» / «№ 31, 18 кг»);
- разные фасовки (12 кг / 20,6 л / ведро 22 кг);
- разные форматы выдачи (schema.org microdata vs. обычный HTML).

## Источники

| Сайт | Позиций | С ценой | Особенности |
|---|---|---|---|
| ksk24.ru | 15 | 15 | обычный HTML, пагинация |
| tophouse.ru | 16 | 3 | HTML, часть цен подгружается JS |
| td-marman.ru | 19 | 19 | schema.org microdata |

Также рассматривались `vseinstrumenti.ru`, `stroy-podskazka.ru`,
`stroy-respublika.ru` — отброшены из-за rotate-капчи и нестабильной
выдачи. В финальную версию вошли три источника.

## Требования

- Python 3.10+
- Windows / Linux / macOS
- ~200 МБ свободного места (Playwright + Chromium)

## Установка

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux / macOS

pip install -r requirements.txt
playwright install chromium    # обязательно: скачивает браузер (~120 МБ)
```

## Запуск

```bash
python main.py             # сбор цен → output/bitumen_prices.csv
python pivot_builder.py    # нормализация → output/bitumen_prices_summary.csv
```

`main.py` обходит три сайта последовательно. Между запросами выдерживаются
паузы 2.5–4.5 секунды, чтобы не выглядеть ботом. Полный прогон занимает
~4–5 минут. Прогресс пишется в `output/parser.log` и `output/pivot.log`.

## Результаты

**50 позиций** собрано с **3 сайтов** → **22 товарные группы**,
из них **15 групп** с прямым сравнением цен между магазинами.

## Как работает нормализация названий

Ключ группы собирается из двух частей:

1. **Маркер продукта** — таблица алиасов (`PRODUCT_ALIASES` в
   `pivot_builder.py`): `фиксер` → `n23_фиксер`, `№31` → `n31`,
   `пламя стоп` → `пламя_стоп` и т.д.
2. **Фасовка** — функция `_canonical_package`: «20 кг» → `20кг`,
   «3,6 кг» → `3.6кг`, «310 мл» → `310мл`.

Два специальных правила решают пограничные случаи:

- `FORCE_PACKAGE = {"пламя_стоп": "20кг"}` — у ksk24 фасовка не указана,
  но у ТехноНИКОЛЬ Пламя Стоп существует только в 20 кг. Подставляем
  единую фасовку, чтобы обе позиции слились в одну группу.
- `IGNORE_PACKAGE_MARKERS = {"n31"}` — у источников разные единицы
  (л vs кг), поэтому фасовка в ключе игнорируется.

## Известные ограничения

1. **№31** — сравнивается без приведения единиц (л vs кг). См. сноску
   в таблице результатов.
2. **tophouse.ru** — из 16 позиций цены удаётся получить только у 3.
   Остальные сайт отдаёт через JS, который парсер пока не выполняет.
   В топе разниц tophouse фигурирует как «дорогая сторона», но полного
   покрытия по нему нет.
3. **№33 водоэмульсионная** — у td-marman фасовка 200 кг (мешок),
   у остальных — ведро. Одна сторона сравнения, поэтому в топ-разницы
   позиция не попадает.
4. **Маркер `"cloudflare"`** в списке антибот-детекции намеренно широкий
   и может давать ложные срабатывания, если Cloudflare упоминается в
   футере живой страницы. На текущих трёх сайтах проблемы нет.
